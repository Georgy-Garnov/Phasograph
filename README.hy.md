# Ֆազոգրաֆ CAD (Phasograph CAD) — 0.4 / 10 կՎ փողոցային էլեկտրական ցանցերի թվայնացում

[English](README.md) · [Русский](README.ru.md) · **Հայերեն** · Առցանց՝ https://georgy-garnov.github.io/Phasograph/

**Ֆազոգրաֆ CAD** (անգլ.՝ **Phasograph CAD**, ռուս.՝ **Фазограф КАД**; անվանումը փոխվում է ինտերֆեյսի լեզվի հետ)
վեբ հավելված է՝ բաշխիչ ցանցերը անմիջապես առցանց քարտեզի վրա քարտեզագրելու համար (OpenStreetMap՝ Leaflet-ի
միջոցով, կամ Yandex Քարտեզներ JS API v3, ընտրվում է վերնագոտում)՝ ենթակայաններ, հենասյուներ, թռիչքներ՝
մեկուսիչների վրա առանձին հաղորդալարերով, ճյուղավորումներ դեպի տներ, և յուրաքանչյուր բաժանորդի ֆազի
ավտոմատ որոշում՝ ենթակայանի ելքերից հետագծման միջոցով։

## Գործարկում

```bash
npm install
npm run dev               # http://localhost:5173 — լռելյայն OpenStreetMap, բանալիներ պետք չեն
npm test                  # միավորային թեստեր (հետագծում, GeoJSON, պահոց, ZIP)
npm run build             # տիպերի ստուգում + կառուցում dist/ պանակում
```

## Նախագծեր, լուսանկարներ, արտահանում

- Մուտքի ժամանակ բացվում է **նախագծերի ցանկը** (պահվում են զննարկչում՝ IndexedDB-ում)՝ ստեղծել, բացել,
  վերանվանել, պատճենել, ջնջել։ Նախագիծը պահպանվում է ավտոմատ։ Նախորդ տարբերակների սխեման (localStorage)
  առաջին գործարկման ժամանակ տեղափոխվում է «Իմ նախագիծը» նախագծի մեջ։
- **Լուսանկարներ** հենասյուների, ենթակայանների և տների համար՝ «📷 Լուսանկարել» կոճակը հեռախոսում կամ
  պլանշետում անմիջապես բացում է տեսախցիկը, լուսանկարը փոքրացվում է (~1920 px) և պահվում նախագծում.
  «🖼 Պատկերասրահից»՝ պատրաստի նկարներ։ Լիաէկրան դիտում, նկարագրություն, ջնջում. քարտեզի վրա լուսանկար
  ունեցող օբյեկտի կողքին երևում է 📷 նշանը։
- **Արտահանում**՝ GeoJSON (միայն սխեման) կամ ZIP՝ `project.geojson` + `photos/*.jpg`
  (GeoJSON-ում օբյեկտներն ունեն `properties.photos = [{ id, file, caption, createdAt }]`)։
  ZIP-ի կամ GeoJSON-ի **ներմուծումը** ստեղծում է նոր նախագիծ։
- **Լեզուներ**՝ ռուսերեն, անգլերեն և հայերեն (🌐 անջատիչը վերնագոտում և նախագծերի էկրանին. լռելյայն՝
  զննարկչի լեզուն)։

## Անցանց աշխատանք և iPad (PWA)

Կառուցված հավելվածը PWA է՝ առաջին բացումից հետո աշխատում է առանց ցանցի։ iPad-ի Safari-ում՝
«Կիսվել» → «Ավելացնել Գլխավոր էկրանին»։ Առցանց դիտված քարտեզի սալիկները պահվում են քեշում
(OSM և արբանյակ՝ մինչև ~8000/4000 սալիկ) և ցուցադրվում առանց ցանցի։ Անցանց ռեժիմը աշխատում է միայն
HTTPS-ով (կամ localhost-ում), ուստի iPad-ի համար հավելվածը պետք է հրապարակել, օրինակ՝ GitHub Pages-ում։

### Հրապարակում GitHub Pages-ում

1. Settings → Pages → Source՝ **GitHub Actions** (այս պահոցի համար արդեն միացված է)։
2. `.github/workflows/pages.yml` workflow-ը `main`/`master` ճյուղ ամեն push-ի ժամանակ գործարկում է
   թեստերը, կառուցում և հրապարակում է `dist/`-ը։ Հասցեն՝ `https://<օգտատեր>.github.io/<պահոց>/`։

Անցանց ռեժիմը տեղում ստուգելու համար՝ `npm run build && npm run preview`, բացեք http://localhost:4173,
ապա անջատեք ցանցը և վերաբեռնեք էջը։

## Աշխարհագրական տվյալների մատակարարներ

Ընտրվում են վերնագոտում և հիշվում զննարկչում։ Սխեման կախված չէ մատակարարից՝ կարելի է փոխել ցանկացած պահի։

| Կարգավորում | Տարբերակներ |
|---|---|
| Քարտեզ | **OpenStreetMap (Leaflet)**՝ անվճար, առանց բանալու. «Քարտեզ» (OSM) և «Արբանյակ» (Esri World Imagery) հիմնաշերտեր։ **Yandex Քարտեզներ** (JS API v3)՝ անհրաժեշտ է բանալի։ |
| Հասցեներ | **Nominatim (OSM)**՝ անվճար, վայրկյանում առավելագույնը 1 հարցում (հարցումները հերթագրվում են)։ **Yandex Գեոկոդեր**՝ անհրաժեշտ է բանալի (հայերեն չի աջակցում, պատասխանում է անգլերեն)։ |

Yandex-ի բանալին «JavaScript API և HTTP Գեոկոդեր» տեսակի է՝ https://developer.tech.yandex.ru/ կայքից.
JS API v3-ի համար պարտադիր է HTTP Referer սահմանափակումը (ավելացրեք `localhost`-ը և աշխատանքային
դոմենը)։ Բանալին մուտքագրվում է Yandex-ն ընտրելիս բացվող ձևում կամ `.env`-ում՝ `VITE_YMAPS_API_KEY`
(տե՛ս `.env.example`)։ Արտադրական օգտագործումից առաջ ստուգեք ծառայությունների պայմանները.
tile.openstreetmap.org-ը և Nominatim-ը նախատեսված են չափավոր բեռնվածության համար՝ հեղինակության նշումով.
շատ օգտատերերի դեպքում անհրաժեշտ է սեփական սալիկների սերվեր կամ առևտրային մատակարար։

## Ինչպես աշխատել

1. **Ենթակայան**՝ տեղադրեք քարտեզի վրա, քարտում նշեք ֆիդերները և յուրաքանչյուր ելքի դերը
   (A, B, C, N, Լուսավորում, ԻՄՀ)։
2. **0.4 կՎ մայրուղային գիծ**՝ սեղմեք ենթակայանի վրա, ապա քարտեզի/հենասյուների վրա։ Դատարկ տեղում
   սեղմելը ստեղծում է հենասյուն։ Հաղորդալարերը դասավորվում են ավտոմատ՝ նոր հենասյան մեկուսիչները կրկնում
   են նախորդինը. «դատարկ» հենասյունից սկսվող գիծը ստանում է 5 հաղորդալարի տիպային եղևնաձև դասավորություն
   (A, B, C, N, լուսավորում. ֆազերը հայտնի կդառնան ենթակայանին միացնելուց հետո)։ Ենթակայանից նույն
   հենասյուն երկրորդ գիծը զբաղեցնում է հաջորդ ազատ ֆիդերը (համատեղ կախոց)։
3. **Հենասյուն** → մեկուսիչների կառուցիչ՝ կողմ (ձախ/աջ/կենտրոն), ներքևից համար՝ ընդհանուր բոլոր կողմերի
   համար (եղևնաձև՝ Ձ1, Ա2, Ձ3, Ա4, Ձ5. ձախ և աջ նույն համարը՝ տրավերս. «կենտրոնում» (Կ)՝ մեկուսիչներ
   հենասյան իրանին, օրինակ՝ T-աձև հենասյան ճյուղավորումը), տեսակ (ձող/կեռ կամ ԻՄՀ սեղմակ), ցատկիչներ
   («⚡ Ցատկիչ» կոճակ և սեղմում երկու մեկուսիչի վրա սխեմայում), միացված հաղորդալարեր։ Մեկուսիչի վրա
   սեղմելը քարտեզի վրա ընդգծում է հաղորդալարն ամբողջ երկարությամբ։
   **ԻՄՀ մալուխ**՝ սեղմակը պահում է ջիղերի հավաքածուով մալուխ. 1+N (ֆազ + զրո), 3+N կամ 3+N+L (լուսավորության
   ջիղով)։ Ջիղերը նշագրված են ինչպես մալուխի վրա (ԳՕՍՏ 31946. ֆազեր 1, 2, 3՝ նույնքան կողիկներով, զրոյական՝ 0,
   լուսավորություն՝ 4) և ներկված են հետագծված ֆազի գույնով. յուրաքանչյուր ջիղ թռիչքների, ճյուղավորումների,
   լուսատուների և ցատկիչների առանձին միացման կետ է, ուստի ֆազը հետագծվում է նաև ԻՄՀ-ով։ Հենասյան սխեմայում մալուխի
   վրա սեղմելը մեծացնում է նրա կտրվածքը՝ ճիշտ ջիղն ընտրելու համար։ Մեկ սեղմակի վրա ընտրված մալուխի տեսակը
   կիրառվում է ԻՄՀ ամբողջ գծի համար։ Մերկ հաղորդալարերով հենասյունից ԻՄՀ թռիչքն ավելացնում է սեղմակ և ցատկիչներ
   մեկուսիչներից նույն դերերի ջիղերին։ Քարտեզի վրա ԻՄՀ թռիչքը սև պատյան է՝ ներսում գունավոր ջիղերով։ Հին
   նախագծերի «փաթեթ» սեղմակները փոխակերպվում են բացելիս։
4. **Գծերի բաժանում**՝ թռիչքի քարտում յուրաքանչյուր հաղորդալարի համար նշվում է հաջորդ հենասյան մեկուսիչը
   («Ձ2-ի վրա էր մինչև X հենասյունը → շարունակվեց Y հենասյան Ա1-ով»). «Ըստ դիրքի» կոճակը համընկնեցնում
   է նույն դիրքերը։ Նույն տրավերսի լուսավորման հաղորդալարը ենթակայանի «Լուսավորում» ելքն է՝ առանձին գծել
   պետք չէ. «Լուսավորման մալուխ» գործիքը առանձին լուսավորման մալուխի համար է (կետագիծ)։
5. **Տուն**՝ սեղմեք շենքի վրա (հասցեն գալիս է ընտրված գեոկոդերից) կամ գծեք նրա **ուրվագիծը**։
   Տան քարտում «Խմբագրել ուրվագիծը»-ն ցույց է տալիս անկյունների և պատերի բռնակները. անկյունները քաշվում են
   մագնիսով դեպի ուղիղ անկյուններ (պատը կանաչում է, մագնիսը բաց է թողնում 10 px-ից հետո), պատերը տեղափոխվում են
   զուգահեռ. փոփոխությունները սևագիր են մինչև «Ավարտել խմբագրումը» (Enter), «Չեղարկել» (Esc)՝ չեղարկում է։
   Կենտրոնի բռնակին սեղմելը փոխում է «ձև» (✥) և «պտտում» (↻) ռեժիմները. ձևի ռեժիմում այն քաշելով տեղաշարժվում է ամբողջ ուրվագիծը, պտտման ռեժիմում ցանկացած անկյուն պտտում է ամբողջ
   ուրվագիծն անշարժ կենտրոնի շուրջ։ Պատերի վրայի մուտքերը պահպանում են իրենց պատն ու տեղը, ուստի ճյուղավորումների
   հետ միասին հետևում են ուրվագծի խմբագրմանը և տան տեղափոխմանը։
6. **Ճյուղավորում**՝ սեղմեք հենասյան, ապա տան/մուտքի վրա։ Ճյուղավորման խմբագրիչում հենասյան սխեմայի
   մեկուսիչների վրա սեղմելով նշվում են ֆազային հաղորդալարը և զրոն (եռաֆազ բաժանորդի համար՝ L1, L2, L3, N)։
   Տան ֆազը հաշվարկվում է և ցուցադրվում նշիչի գույնով. ԻՄՀ մալուխի դեպքում ջիղն ընտրվում է մեծացված
   կտրվածքում (ենթակայանի «ԻՄՀ» փաթեթ ելքի դեպքում ֆազը նշվում է ձեռքով)։ Տան ուրվագծի
   վրա սեղմելը մուտքը տեղադրում է պատին՝ սեղմման կետում. նույն կերպ տներ է մտցվում նաև ՕՄԳ-ն։
7. **Լուսատու հենասյան վրա**՝ հենասյան վրա սեղմելը կախում է լուսատու և այն միացնում լուսավորման
   հաղորդալարին (L) և զրոյին. հենասյան քարտում «Փողոցային լուսավորություն» բաժինն է՝ տեսակ, հզորություն,
   սնուցման և զրոյի մեկուսիչներ։ Քարտեզի վրա հենասյան կողքին ✹ նշանն է (մոխրագույն՝ առանց սնուցման).
   դրա վրա սեղմելը ընտրում է լուսատուն, Del-ը ջնջում է այն։ «Լուսավորություն» հաշվետվության ներդիրում
   լուսատուներն ու հզորությունն ըստ ֆիդերների։
8. Քարտերում երկարություններն են՝ հաշվարկված կոորդինատներից. թռիչքի/ճյուղավորման երկարություն,
   ցանցով հեռավորություն մինչև ենթակայան (0.4 կՎ հաղորդալարերով, ոչ թե ուղիղ գծով. մի քանի ենթակայանի
   դեպքում՝ մինչև մոտական), յուրաքանչյուր ֆիդերի մայրուղային գծի և ճյուղավորումների երկարությունը։
9. «Ստուգում» վահանակը ցույց է տալիս կարճ միացումները (տարբեր ֆազեր մեկ հաղորդալարի վրա), ֆիդերների
   օղակները, չմիացված հաղորդալարերը, առանց զրոյի բաժանորդները, ձեռքով նշված և հաշվարկված ֆազերի
   անհամապատասխանությունները, առանց սնուցման/զրոյի լուսատուները։ «Ֆիդերներ»՝ բաժանորդներն ըստ ֆազերի։

Ստեղնաշարի դյուրանցումներ՝ `Esc`՝ ավարտել գիծը / չեղարկել գործիքը, `Del`՝ ջնջել, `Ctrl+Z` / `Ctrl+Shift+Z`,
`Enter`՝ ավարտել ուրվագիծը։

## Լարման անկման հաշվիչ

Տունն ունի **նախագծային միացման հզորություն** և **ընթացիկ սպառում** (կՎտ), թռիչքն ու ճյուղավորումը՝
**հաղորդալար** տեղեկատուից (մերկ ալյումին А-16…А-95, АС, պղինձ, ԻՄՀ-2 / ԻՄՀ-4՝ r, x մեկ կմ-ի համար. լռելյայն՝
А-35 մերկ մայրուղային գծի, ԻՄՀ-2 3×50+1×54.6 ԻՄՀ-ի, ԻՄՀ-4 2×16 ճյուղավորումների համար), ենթակայանը՝ ֆազային
լարում դողերի վրա (լռելյայն 230 Վ)։ Յուրաքանչյուր ֆիդերի համար կառուցվում է ուղին ենթակայանից մինչև ամեն տուն
հետագծված թռիչքներով, բեռները գումարվում են ըստ ֆազերի, զրոյի հոսանքը ֆազային հոսանքների վեկտորական գումարն է,
ուստի անհավասար ֆազավորումը երևում է որպես չեզոքի շեղում։ Յուրաքանչյուր տան կողքի **մինի վոլտմետրը** ցույց է
տալիս ֆազային լարումը մուտքում (կանաչ՝ 207–253 Վ, ±10%, կարմիր՝ նորմայից դուրս. եռաֆազ տանը՝ երեք
ցուցիչ՝ մեկական A, B, C ֆազի համար. եռաֆազ տան բեռնվածքը կարելի է տալ ըստ ֆազերի՝ «Բեռնվածքն ըստ ֆազերի» տան
քարտում, այլապես ընդհանուրը բաշխվում է հավասարապես)։ Հաշվետվության «Լարում» ներդիրը՝ ընթացիկ/նախագծային բեռի ռեժիմ, վոլտմետրերի միացում, տներն ըստ լարման
աճման։ cos φ = 0.95. դիմադրությունները տիպային արժեքներ են 20 °C-ում։

**Ենթակայան (տրանսֆորմատոր)։** Ենթակայանի քարտում նշվում են տրանսֆորմատորի հզորությունը (ստանդարտ շարք
25…2500 կՎԱ, տեսակը ցուցադրվում է որպես «ԿՏԵ-250/10/0,4»), ԲԼ դասը (6 կամ 10 կՎ), ԲԼ փաստացի լարումը (անկման
նմանակման համար, օրինակ՝ 5500 Վ 6000-ի փոխարեն) և ԱԳՓ դիրքը (+5 / +2.5 / 0 / −2.5 / −5 % ԲԼ փաթույթի)։ 0.4 կՎ
պարապ ընթացքի լարումը = 230.9 Վ × (U_ԲԼ / U_ԲԼ անվ) / (1 + ճյուղավորում). բեռի տակ դողերի լարումը նվազում է
տրանսֆորմատորի կարճ միացման դիմադրության վրա՝ բոլոր ֆիդերների հոսանքների գումարից։ Ենթակայանի կողքին
նույնպիսի մինի սարքերի վահանակ է՝ դողերի լարումներն ու հոսանքները ըստ ֆազերի, բեռը կՎԱ-ով և անվանականի %-ով,
ԲԼ լարումն ու հոսանքը։ Բարձր լարման հենասյուներն ու գծերը նշված են որպես 6/10 կՎ։

**Կրկնակի հողակցում։** Հենասյան վրա կարելի է նշել զրոյական (PEN) հաղորդալարի կրկնակի հողակցում՝ հողակցիչի
դիմադրությամբ (լռելյայն՝ 30 Օմ, ԷՍԿ 1.7.103). տրանսֆորմատորի չեզոքի հողակցումը լռելյայն 4 Օմ է (ԷՍԿ 1.7.101)։
Կրկնակի հողակցումների առկայության դեպքում զրոն հաշվարկվում է որպես հանգուցային սխեմա՝ հողը որպես ընդհանուր
հանգույց. անհամաչափության դեպքում զրոյի հոսանքի մի մասը վերադառնում է հողով։ Նորմալ ռեժիմում ֆազային լարումները
քիչ են փոխվում, սակայն զգալիորեն նվազում է զրոյի պոտենցիալը հողի նկատմամբ. հենասյան քարտում երևում են հողակցիչի
հոսանքը և զրոյի պոտենցիալը, տան քարտում՝ զրոյի լարումը հողի նկատմամբ մուտքում։

**Ստորգետնյա մուտք։** Ճյուղավորումը կարելի է նշել որպես ստորգետնյա. մալուխն իջնում է հենասյունով (6 մ), անցնում
խրամատով (1,5 մ խորություն) և բարձրանում պատով մինչև մուտքը (2 մ)՝ բոլորը խմբագրելի են։ Այս ուղղահայաց
հատվածներն ավելանում են ճյուղավորման երկարությանը և հաշվի են առնվում լարման հաշվարկում. լռելյայն հաղորդալարը
զրահապատ АВБбШв մալուխ է։ Քարտեզի վրա ճյուղավորման տակ գծվում է շագանակագույն խրամատ։

## Տվյալների մոդել

`src/model/types.ts`։ Հանգույցներ (Point)՝ `ktp`, `pole10`, `pole04`, `poleService`, `entry`, `house`
(ոչ պարտադիր ուրվագծով)։ Գծեր (LineString երկու հանգույցի միջև)՝ `line10`, `line04`, `drop`, `lighting`, `fiber`։

Հաղորդալարը `{ id, fromPort, toPort }` է, որտեղ պորտը հենասյան մեկուսիչի կամ ենթակայանի ելքի id-ն է
(մուտքի/տան մոտ պորտ պետք չէ)։ Հենասյան ցատկիչը միացնում է նրա երկու մեկուսիչ։

GeoJSON (`src/model/geojson.ts`)՝ FeatureCollection, բոլոր ատրիբուտներն ու կապերը՝ `properties`-ում.

```json
{ "type": "Feature", "geometry": { "type": "Point", "coordinates": [37.61, 55.75] },
  "properties": { "kind": "pole04", "id": "pole04_…", "number": "12",
    "insulators": [{ "id": "ins_1", "side": "L", "position": 1, "type": "pin" }], "jumpers": [] } }
{ "type": "Feature", "geometry": { "type": "LineString", "coordinates": [[…], […]] },
  "properties": { "kind": "line04", "from": "pole04_…", "to": "pole04_…", "suspension": "bare",
    "wires": [{ "id": "w_1", "fromPort": "ins_1", "toPort": "ins_7" }] } }
```

Արտահանման ժամանակ ավելանում է `properties.trace`-ը (տների և հաղորդալարերի հաշվարկված ֆազերը), ներմուծման
ժամանակ այն անտեսվում է։ Առանց `from`/`to`-ի գծերը կապվում են իրենց ծայրերից 3 մ շառավղում գտնվող
հանգույցներին։

## Հետագծման ալգորիթմ

`src/topology/trace.ts`։ Գրաֆի գագաթները սեղմակներն են (ենթակայանի ելք, մեկուսիչ, հաղորդալարի ծայրը մուտքի
մոտ), կողերը՝ հաղորդալարերն ու ցատկիչները։ Ենթակայանի յուրաքանչյուր ելքից սկսվում է լայնությամբ որոնում
`{ֆիդեր, դեր}` նշանով։ ԻՄՀ մալուխի յուրաքանչյուր ջիղ առանձին սեղմակ է, ուստի ֆազերն անցնում են ԻՄՀ-ով
անփոփոխ. միայն ենթակայանի «ԻՄՀ» ելքը (անհայտ ջիղերով փաթեթ) նշանները նշում է որպես «փաթեթ»՝ ֆիդերը
հայտնի է, ֆազը՝ ոչ։ Միաֆազ տունը ստանում է իր ճյուղավորումների հաղորդալարերի միակ
միանշանակ ֆազը։ Հաղորդալարերի ձեռքով նշագրումները հանդես են գալիս որպես լրացուցիչ աղբյուրներ և
ստուգվում են ենթակայանից հետագծման արդյունքով։

## Նախագծի կառուցվածք

```
src/model      տիպեր, սխեմայի գործողություններ, store (undo/redo, նախագծի ավտոմատ պահպանում), GeoJSON
src/storage    IndexedDB (նախագծեր, լուսանկարներ), ZIP արխիվ, լուսանկարների փոքրացում
src/i18n       տեղայնացում՝ ru.ts (բանալիների հիմնական հավաքածու), en.ts, hy.ts, օբյեկտների պիտակներ
src/topology   հետագծում և ստուգումներ, երկարություններ և հեռավորություններ մինչև ենթակայան (distances.ts)
src/map        scene.ts՝ ինչ նկարել (զուգահեռ հաղորդալարեր՝ պիքսելային շեղումով), մատակարարից անկախ.
               adapter.ts՝ ինտերֆեյս և diff թարմացումներ. leafletAdapter.ts / yandexAdapter.ts՝ մատակարարներ.
               geocoder.ts՝ Nominatim / Yandex. interactions.ts՝ գծագրման գործիքներ
src/ui         վահանակներ՝ ենթակայան, մեկուսիչների կառուցիչ, թռիչք/ճյուղավորում, բաժանորդ, հաշվետվություններ,
               նախագծեր, լուսանկարներ
```
