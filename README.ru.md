# Фазограф КАД (Phasograph CAD) — оцифровка уличных электросетей 0.4 / 10 кВ

[English](README.md) · **Русский** · [Հայերեն](README.hy.md) · Онлайн: https://georgy-garnov.github.io/Phasograph/

**Фазограф КАД** (англ. **Phasograph CAD**, арм. **Ֆազոգրաֆ CAD**; название меняется вместе с языком интерфейса) — веб-приложение для картографирования распределительных сетей прямо на онлайн-карте
(OpenStreetMap через Leaflet или Яндекс Карты JS API v3 — переключается в шапке):
КТП, опоры, пролёты с отдельными проводами на изоляторах, отводы к домам — и автоматическое
вычисление фазы каждого абонента трассировкой от выходов КТП.

## Запуск

```bash
npm install
npm run dev               # http://localhost:5173 — по умолчанию OpenStreetMap, ключи не нужны
npm test                  # тесты трассировки и GeoJSON
npm run build             # проверка типов + сборка в dist/
```

## Проекты, фото, экспорт

- При входе — **список проектов** (хранятся в браузере, в IndexedDB): создать, открыть, переименовать,
  сделать копию, удалить. Проект сохраняется автоматически. Схема из прежних версий (localStorage)
  при первом запуске переносится в проект «Мой проект».
- **Фото** — у опор, КТП и домов: кнопка «📷 Сфотографировать» на телефоне/планшете сразу открывает камеру,
  после съёмки фото сжимается (~1920 px) и сохраняется в проекте; «🖼 Из галереи» — готовые снимки.
  Просмотр на весь экран, подпись, удаление; на карте у объекта с фото — значок 📷.
- **Экспорт**: GeoJSON (только схема) или ZIP — `project.geojson` + `photos/*.jpg`
  (у объектов в GeoJSON `properties.photos = [{ id, file, caption, createdAt }]`).
  **Импорт** ZIP или GeoJSON создаёт новый проект.
- **Языки**: русский, английский и армянский (переключатель 🌐 в шапке и на экране проектов; по умолчанию —
  язык браузера).

## Офлайн и iPad (PWA)

Собранное приложение — PWA: после первого открытия работает без сети. В Safari на iPad:
«Поделиться» → «На экран „Домой“». Тайлы карты, которые вы просматривали онлайн, кэшируются
(OSM и спутник — до ~8000/4000 тайлов) и показываются без сети. Офлайн-режим работает только по HTTPS
(или на localhost), поэтому для iPad приложение нужно опубликовать — например, на GitHub Pages.

### Публикация на GitHub Pages

1. Settings → Pages → Source: **GitHub Actions** (уже включено для этого репозитория).
2. Workflow `.github/workflows/pages.yml` при пуше в `main`/`master` прогоняет тесты, собирает и публикует
   `dist/`. Адрес — `https://<пользователь>.github.io/<репозиторий>/`.

Проверить офлайн локально: `npm run build && npm run preview`, открыть http://localhost:4173, затем
отключить сеть и перезагрузить страницу.

## Провайдеры геоданных

Выбираются в шапке, выбор запоминается в браузере. Схема не зависит от провайдера — переключаться можно в любой момент.

| Настройка | Варианты |
|---|---|
| Карта | **OpenStreetMap (Leaflet)** — бесплатно, без ключа; подложки «Схема» (OSM) и «Спутник» (Esri World Imagery). **Яндекс Карты** (JS API v3) — нужен ключ. |
| Адреса | **Nominatim (OSM)** — бесплатно, не чаще 1 запроса/с (запросы ставятся в очередь). **Яндекс Геокодер** — нужен ключ. |

Ключ Яндекса — «JavaScript API и HTTP Геокодер» из https://developer.tech.yandex.ru/; для JS API v3 обязательно
ограничение по HTTP Referer (добавьте `localhost` и рабочий домен). Ключ вводится в форме при выборе Яндекса
или задаётся в `.env` (`VITE_YMAPS_API_KEY`, см. `.env.example`).
Перед продуктивным использованием проверьте условия сервисов: tile.openstreetmap.org и Nominatim — для умеренной
нагрузки с указанием авторства; при большом числе пользователей нужен свой тайл-сервер или коммерческий провайдер.


## Как работать

1. **КТП** — поставить на карту, в карточке задать фидеры и роль каждого выхода (A, B, C, N, Фонарь, СИП).
2. **Магистраль 0.4 кВ** — клик по КТП, затем клики по карте/опорам. Клик в пустое место создаёт опору.
   Провода раскладываются автоматически: изоляторы новой опоры повторяют предыдущую; магистраль от «пустой»
   опоры получает типовую ёлочку из 5 проводов (A, B, C, N, фонарь — фазы станут известны после подключения к КТП).
   Повторная линия от КТП к той же опоре занимает следующий свободный фидер (совместный подвес).
3. **Опора** → конструктор изоляторов: сторона (слева/справа), номер снизу — общий для обеих сторон
   («ёлочка»: Л1, П2, Л3, П4, Л5; одинаковый номер слева и справа — траверса; «по центру» (Ц) — изоляторы
   на теле опоры, например ответвление на Т-образной опоре), тип (штырь/зажим СИП),
   перемычки (кнопка «⚡ Перемычка» и клик по двум изоляторам на схеме), подключённые провода. Клик по изолятору подсвечивает провод на карте по всей длине.
4. **Развилка** — в карточке пролёта для каждого провода указывается изолятор на следующей опоре
   («шёл на Л2 до опоры X → пошёл на П1 опоры Y»), кнопка «По положению» сопоставляет одинаковые позиции.
   Фонарный провод на той же траверсе — это выход «Фонарь» КТП, рисовать его отдельно не нужно.
   Инструмент «Уличное освещение» — для отдельного кабеля освещения (пунктир).
5. **Дом** — клик по зданию (адрес подтягивается выбранным геокодером) или обвести **контур**.
   «Редактировать контур» в карточке дома показывает ручки углов и стен: углы тянутся с магнитом к прямым
   углам (стена подсвечивается зелёным, магнит отпускает дальше 10 px), стены сдвигаются параллельно себе;
   изменения — черновик до «Завершить редактирование» (Enter), «Отмена» (Esc) их отбрасывает. Ручка в центре
   переключает режимы «форма» (✥) и «вращение» (↻): во вращении любой угол поворачивает весь контур вокруг
   неподвижного центра. Вводы на стенах сохраняют свою стену и место на ней, поэтому вместе с отводами следуют
   за правкой контура и перемещением дома.
6. **Отвод** — клик по опоре, затем по дому/вводу. В редакторе отвода кликом по изоляторам на схеме опоры
   указываются фазный провод и ноль (для 3-фазного абонента — L1, L2, L3, N).
   Фаза дома вычисляется и показывается цветом маркера; для СИП фаза указывается вручную.
   Клик по контуру дома ставит ввод на стене в точке клика. Так же к домам заводится ВОЛС.
7. **Фонарь на опоре** — инструмент на панели: клик по опоре вешает фонарь и подключает его к фонарному
   проводу (L) и нулю; в карточке опоры раздел «Уличное освещение» — тип, мощность, изоляторы питания и нуля.
   На карте значок ✹ у опоры (серый — без питания); клик по нему выбирает фонарь, Del удаляет фонарь
   (кнопка «Удалить фонарь» — в карточке). В отчёте вкладка «Освещение» — фонари и мощность по фидерам.
8. В карточках — длины, посчитанные по координатам: длина пролёта/отвода, расстояние до КТП по сети
   (по проводам 0.4 кВ, а не по прямой; при нескольких КТП — до ближайшей), протяжённость магистрали и
   отводов каждого фидера (в карточке КТП).
9. Панель «Проверка» — КЗ (разные фазы на одном проводе), кольца фидеров, неподключённые провода,
   абоненты без нуля, расхождение ручной и вычисленной фазы, фонари без питания/нуля. «Фидеры» — распределение абонентов по фазам.

Горячие клавиши: `Esc` — завершить линию/отменить инструмент, `Del` — удалить, `Ctrl+Z` / `Ctrl+Shift+Z`, `Enter` — завершить контур.

## Калькулятор падения напряжения

У дома — **проектная мощность подключения** и **текущее потребление** (кВт); у пролёта и отвода — **провод** из
справочника (голый алюминий А-16…А-95, АС, медь, СИП-2 / СИП-4 с r, x на км; по умолчанию А-35 для голой
магистрали, СИП-2 3×50+1×54,6 для СИП, СИП-4 2×16 для отводов); у КТП — фазное напряжение на шинах (230 В по
умолчанию). Для каждого фидера строится путь от КТП до каждого дома по прослеженным пролётам, нагрузки
суммируются по фазам, ток в нуле — векторная сумма фазных токов, поэтому неравномерная фазировка видна как
сдвиг нейтрали. **Мини-вольтметр** у каждого дома показывает фазное напряжение на вводе (зелёный — 207–253 В,
±10% по ГОСТ 32144, красный — вне нормы; для трёхфазного — минимальная фаза). Вкладка «Напряжение» в отчёте:
режим «текущее потребление / проектная мощность», включение вольтметров, дома от самого низкого напряжения.
cos φ = 0,95; сопротивления — типовые значения при 20 °C.

**КТП (трансформатор).** В карточке КТП задаются мощность трансформатора (стандартный ряд 25…2500 кВА; тип
показывается как «КТП-250/10/0,4»), класс ВН (6 или 10 кВ), фактическое напряжение ВН (для эмуляции просадки,
например 5500 В вместо 6000) и положение ПБВ (+5 / +2,5 / 0 / −2,5 / −5 % обмотки ВН). Напряжение холостого хода
0,4 кВ = 230,9 В × (U_ВН / U_ВН ном) / (1 + отпайка); под нагрузкой напряжение на шинах снижается на
сопротивлении КЗ трансформатора (типовые uk и потери КЗ для мощности) от суммы токов всех фидеров. Рядом с КТП —
панель таких же мини-приборов: напряжения и токи шин по фазам, нагрузка в кВА и % от номинала, напряжение и ток
ВН. Опоры и линии высокого напряжения подписаны как 6/10 кВ.

## Модель данных

`src/model/types.ts`. Узлы (Point): `ktp`, `pole10`, `pole04`, `poleService`, `entry`, `house` (с необязательным контуром).
Линии (LineString между двумя узлами): `line10`, `line04`, `drop`, `lighting`, `fiber`.

Провод — `{ id, fromPort, toPort }`, где порт — id изолятора опоры или id выхода КТП
(на вводе/доме порт не нужен). Перемычка опоры соединяет два её изолятора.

GeoJSON (`src/model/geojson.ts`): FeatureCollection, все атрибуты и связи — в `properties`:

```json
{ "type": "Feature", "geometry": { "type": "Point", "coordinates": [37.61, 55.75] },
  "properties": { "kind": "pole04", "id": "pole04_…", "number": "12",
    "insulators": [{ "id": "ins_1", "side": "L", "position": 1, "type": "pin" }], "jumpers": [] } }
{ "type": "Feature", "geometry": { "type": "LineString", "coordinates": [[…], […]] },
  "properties": { "kind": "line04", "from": "pole04_…", "to": "pole04_…", "suspension": "bare",
    "wires": [{ "id": "w_1", "fromPort": "ins_1", "toPort": "ins_7" }] } }
```

При экспорте добавляется `properties.trace` (вычисленные фазы домов и проводов), при импорте он игнорируется.
Линии без `from`/`to` привязываются к узлам в пределах 3 м от концов.

## Алгоритм трассировки

`src/topology/trace.ts`. Граф: вершины — клеммы (выход КТП, изолятор, конец провода на вводе),
рёбра — провода и перемычки. От каждого выхода КТП — обход в ширину с меткой `{фидер, роль}`.
Зажим СИП (и выход «СИП») объединяет жилы: метки за ним помечаются как «жгут» — фидер известен, фаза нет.
Фаза однофазного дома = единственная однозначная фаза среди проводов его отводов.

## Структура

```
src/model      типы, операции над схемой, store (undo/redo, автосохранение проекта), GeoJSON
src/storage    IndexedDB (проекты, фото), ZIP-архив, сжатие фото
src/i18n       локализация: ru.ts (эталон ключей), en.ts, hy.ts, подписи объектов
src/topology   трассировка и проверки, длины и расстояния до КТП (distances.ts)
src/map        scene.ts — что рисовать (провода параллельно со смещением в пикселях), независимо от провайдера;
               adapter.ts — интерфейс и diff-обновление; leafletAdapter.ts / yandexAdapter.ts — провайдеры;
               geocoder.ts — Nominatim / Яндекс; interactions.ts — инструменты рисования
src/ui         панели: КТП, конструктор изоляторов, пролёт/отвод, абонент, отчёты
```
